# Agent brief: hand-match near functions (Heroes of Mana)

Reusable prompt body for "N agents for N functions" rounds. Replace {NAMES} (list). The orchestrator builds batches
with `python ../../studio/gametools/agentdeal.py N PER [--skip-thunks]` (writes build/hunt/batchK/agentI.txt).

---
You hand-match Nintendo DS (mwccarm) functions of Heroes of Mana. Project dir:
`D:\... logiciel\decomp\decomp ds\projets\heroes-of-mana` (cwd for every command). Setup once per shell (PowerShell):
`. "..\..\env.ps1"` (Bash: `source ../../env.sh`).

Your functions: {NAMES}

For each function:
1. `python ../../studio/gametools/hunt.py show NAME` -> best draft so far + diff (TARGET | CANDIDATE, `*` = differing line).
2. Edit a copy of the draft in your own dir `build/hunt/agents/NAME.c` (create it; this is also where the final answer goes).
3. Judge: `python ../../studio/gametools/workbench.py judge NAME build/hunt/agents/NAME.c --profile "P"` where P is the
   profile printed by `show` (e.g. `2.0/sp1p5`, `1.2/sp3`, `2.0/sp1p5 -profile`). Faster for ideas:
   `python ../../studio/gametools/tryc.py NAME 'C variant 1' 'C variant 2' -p P`; `mdiff.py NAME FILE.c P` (structural diff).
   Other tools in ../../studio/gametools: permrand.py, stmtperm.py (tag statements `/*P*/`), optsweep.py; target asm = `workbench.py info NAME`. Try 1.2/sp3 and 1.2/sp2p3 too: the printed profile is often wrong.
4. Goal: judge says MATCH (0 diffs). Budget ~10 min per function; if stuck, move on. Give up on a function after
   ~8 judge runs without progress.

Known fixes: u8* pointer arithmetic (m2c scaled `p + 0x18`), extern type u8 vs s32, `for`/`do while` instead of goto loops, temp var
for call result (`s32 t = f(); return t + a;`), early return, declaration order of locals, statement order of independent stores,
field copied to a local before a compare, typedef struct with vtable for virtual calls `(*(R (**)(void *))(*(u8 **)obj + K))(obj)`,
unused leading param, struct assign instead of 2-word copies, `volatile` on HW regs. Profile `-profile` funcs: ignore the
`func_0200fb24/fb28` hook calls (they are generated by the compiler flag).

Status `compile` / `size` (handed out with `agentdeal.py --status compile,size` once near ones are exhausted):
the m2c draft does not compile or has the wrong size. Rewrite it from the TARGET asm (`python ../../studio/gametools/workbench.py info NAME`)
instead of patching blindly: fix undeclared vars / `M2C_*` leftovers / `void *` arithmetic, pick real types (u8/u16/s16 loads,
`(u8 *)&sym + off` bytes, struct arrays), restore dropped args. Small functions: aim for a clean rewrite in 2-4 judges.
Skip fast (1 judge) obvious non-C: C++ EH fragments, hand asm (`swp`, `mcr`, odd regs), `__sinit`, `ldr ip,=0xfffffffc` thunks.
If your round has its own dir (e.g. `build/hunt/r15/a1/`), write files there instead of `build/hunt/agents/`. Keep helper
scripts in that dir too, never in /tmp (shared by the parallel agents: they overwrite each other).

Profile hints: ov123 functions are almost always 1.2/sp3 or 1.2/sp2p3 (judge 1.2/sp3 FIRST there); `sub sp,sp,#4` after an odd-count push (instead of `push {r3,...}`) => 1.2/sp3; `func_0200fb24/fb28` hook calls
=> add ` -profile`. Other proven fixes: `if (i < end) do {...} while` moves pointer setup after the guard; one-word struct by
value gives `add r1,sp,#N; ldr r1,[r1]`; `push {r0-r3}` prologue = varargs `(a, b, c, d, ...)`; C++ EH (`__rethrow`,
`__end__catch`, fp frames) = skip. A value set in r1/r2/r3 before a call and otherwise unused = a hidden extra ARGUMENT of
that call (m2c drops it). Bitfield structs (`u32 f:1`) for lsl/lsr/bic/orr; first-declared local gets the higher register.

RULES (violations make the match rejected):
- ASCII sources, English comments. `#include "m2c.h"` is fine; NO asm, `#define`, `#pragma`, other `#include`, `__attribute__`, `##` in the C.
- ONLY judge. NEVER run `hunt.py try/note/park/sweep`, `workbench.py submit/commit`, git, or touch other files than
  `build/hunt/agents/*.c`: parallel writes corrupt shared state.
- Never use leaked SDK source.

Final answer (short): for each function `NAME: MATCH <profile>` (file written) or `NAME: no (best N diffs, what blocks)`.
